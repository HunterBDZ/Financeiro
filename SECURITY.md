# Segurança

## Como relatar uma falha

Não abra uma issue pública. Use **Security → Report a vulnerability** neste repositório, para que o relato fique privado até haver correção.

Inclua, se puder, a versão (`VERSION` ou o fim da tela Ajustes), os passos para reproduzir e o impacto. Não envie dados financeiros reais.

## Versões cobertas

Só a última versão publicada (a maior tag `vX.Y.Z`) recebe correções. Para atualizar, rode `sudo financeiro-atualizar`.

## Alcance

O app foi feito para a rede de casa, atrás de uma VPN quando acessado de fora. Relatos sobre o app, o instalador e o atualizador são bem-vindos. Exposição direta à internet, por escolha de quem instalou, e o aviso de certificado autoassinado estão fora do alcance.

As proteções do app e o que sai do servidor estão em [`docs/SEGURANCA.md`](docs/SEGURANCA.md).

## In English

Please do not open a public issue. Use **Security → Report a vulnerability** in this repository. Only the latest published version receives fixes.
